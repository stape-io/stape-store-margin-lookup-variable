# Stape Store Margin Lookup Variable for Google Tag Manager Server Container

The **Stape Store Margin Lookup Variable** for GTM Server allows you to **retrieve margin data** from **Stape Store** for each product in your `items` array and returns a **combined margin value** that accounts for quantity, enabling you to track **Profit on Ad Spend (ROAS)** for your conversion events and advertising campaigns.
